# Project: Tic-Tac-Toe 🏕️

### Goal: Create a two-player Tic-Tac-Toe game using object-oriented programming (OOP)

## Result: A camping-themed Tic-Tac-Toe game 🌲

* A two-player game where users take turns placing 🌲s and 🏕️s.
* Displays a message in the DOM when a player wins.
* Uses a camping-inspired green color scheme.

## Future improvements

* Refactor the code to use more object-oriented programming (OOP)
* Add a reset button
* Track wins for each player
